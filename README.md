# 多普勒效应虚拟实验

一个基于 HTML5、CSS3 和原生 JavaScript 开发的交互式多普勒效应模拟网页应用，通过可视化方式直观展示声源与观察者之间相对运动时产生的多普勒效应现象。

## 功能特性

### 交互式模型
- 可拖拽的声源与观察者图形模型，支持在二维平面内自由移动
- 直观的参数控制面板，包含：
  - 声源频率调节滑块（范围：20Hz-20000Hz，步长1Hz）
  - 声源运动速度控制（范围：0-340m/s，步长0.1m/s）
  - 声源运动方向控制（范围：0-360°）
  - 观察者运动速度控制（范围：0-340m/s，步长0.1m/s）
  - 观察者运动方向控制（范围：0-360°）
  - 环境声速设置（默认340m/s，可调节范围：200-400m/s）
- 预设场景快速切换

### 实时计算与数据展示
- 基于多普勒效应公式实时计算观察到的频率值
- 数据显示面板同步展示：
  - 声源原始频率（Hz）
  - 声源运动速度及方向（m/s）
  - 观察者运动速度及方向（m/s）
  - 计算得到的观察频率（Hz）
  - 频率变化百分比（%）
  - 相对速度（m/s）
- 数据实时更新，响应时间不超过100ms

### 可视化波形展示
- 双波形对比显示区域：
  - 声源原始频率波形（红色）
  - 观察者接收到的频率波形（绿色）
- 波形图包含时间轴与振幅轴
- 支持缩放查看功能
- 波形动态更新，帧率不低于30fps

### 动态模拟动画
- 声波传播动态可视化，以同心圆形式从声源向外扩散
- 根据相对运动速度实时调整波前密度
- 速度矢量箭头显示运动方向
- 支持暂停/播放控制

### 用户界面
- 响应式布局，支持桌面端（最小宽度1024px）与平板设备
- 深色主题配色，直观的色彩编码系统
- 可折叠的实验原理与操作指南面板
- 场景保存/加载功能

## 技术实现

### 文件结构

```
NO5/
├── index.html          # 主HTML页面
├── css/
│   └── styles.css      # 响应式样式文件
└── js/
    ├── doppler.js      # 多普勒效应计算核心模块
    ├── waveform.js     # 波形显示模块
    ├── simulation.js   # Canvas动画和声波可视化模块
    └── app.js          # 主应用逻辑和交互控制
```

### 技术栈
- **HTML5 Canvas** - 动态图形绘制
- **CSS3** - 响应式布局与动画效果
- **原生 JavaScript** - 交互逻辑实现
- **LocalStorage** - 场景数据持久化

### 多普勒效应公式

```
f' = f × (v + vₒ) / (v - vₛ)
```

其中：
- **f'** - 观察者接收到的频率
- **f** - 声源原始频率
- **v** - 声速
- **vₒ** - 观察者速度（靠近声源为正）
- **vₛ** - 声源速度（靠近观察者为正）

## 快速开始

### 本地运行

1. 克隆或下载项目到本地

2. 使用任意 HTTP 服务器运行，例如：

```bash
# 使用 Python 3
cd NO5
python3 -m http.server 8080

# 或使用 Node.js 的 http-server
npx http-server -p 8080
```

3. 在浏览器中打开 `http://localhost:8080`

### 直接打开

由于使用了原生 JavaScript，也可以直接在浏览器中打开 `index.html` 文件（部分浏览器可能需要允许本地文件访问）。

## 使用说明

### 基本操作

1. **调节参数**：使用左侧控制面板的滑块或输入框调节各项参数
2. **移动元素**：在画布中拖拽声源（S）或观察者（O）改变位置
3. **观察变化**：查看波形变化和实时数据更新
4. **使用预设**：选择预设场景快速体验典型情况

### 预设场景

| 场景名称 | 描述 |
|---------|------|
| 声源接近观察者 | 声源以30m/s向观察者移动 |
| 声源远离观察者 | 声源以30m/s远离观察者 |
| 两者相向运动 | 声源和观察者各以20m/s相向运动 |
| 救护车效应 | 模拟救护车经过时的经典案例 |
| 超音速演示 | 声源以接近声速运动 |

### 控制按钮

- **播放/暂停**：控制动画运行状态
- **重置**：恢复所有参数到默认值
- **保存**：保存当前参数配置到本地存储
- **加载**：加载已保存的场景配置
